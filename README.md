# Science of the Unseen

Companion material for the book *A Mathematical and Scientific Approach to the Unseen*
by Weqaar Janjua. Website: <https://scienceofunseen.com>.

## Contents

| Folder | What it holds |
|---|---|
| [`HISA/`](HISA/) | **HISA, the Human Instruction Set Architecture.** An explanatory model [B] that describes a person in the vocabulary of a processor's instruction set, including the `N` extension for the nervous system as a self-rewiring neural network. Start with [`HISA/README.md`](HISA/README.md). |

HISA is an analogy, not a description of what a person is. The book holds that a human
being remains more than a machine executing instructions, and HISA follows that position.
